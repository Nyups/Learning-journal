# HTML Review Cheat Sheet

---

# 1. HTML Basics

- **HTML (HyperText Markup Language)** = Defines the structure of a webpage.
- HTML is made of **elements (tags)**.
  - Most have an opening and closing tag.
  - Example:
    ```html
    <p>Hello</p>
    ```
- **Void elements** have NO closing tag.
  - Examples:
    ```html
    <img>
    <br>
    <hr>
    <input>
    ```
- **Attributes** provide extra information.
  ```html
  <img src="cat.jpg" alt="Cat">
  ```

---

# 2. Basic HTML Structure (Boilerplate)

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Title</title>
</head>
<body>

</body>
</html>
```

- `<!DOCTYPE html>` → HTML5 document.
- `<html>` → Root element.
- `<head>` → Metadata, CSS, scripts.
- `<body>` → Visible content.
- UTF-8 supports almost every character.

---

# 3. Common Elements

## Headings

```html
<h1>Largest Heading</h1>
<h6>Smallest Heading</h6>
```

Always keep hierarchy:

```
h1
 └── h2
      └── h3
```

Don't skip heading levels.

---

## Paragraph

```html
<p>Paragraph</p>
```

---

## Div

Generic container.

```html
<div>Content</div>
```

Has **no semantic meaning**.

---

# 4. IDs vs Classes

## id

Unique.

```html
<div id="header"></div>
```

One per page.

---

## class

Reusable.

```html
<div class="card"></div>
```

Many elements can share the same class.

Use meaningful elements.

```

<nav>
<main>
<section>
```

# 17. Accessibility Best Practices

✔ Proper heading hierarchy

✔ Label every input

✔ Good alt text

✔ Descriptive link text

✔ Captions & transcripts for videos

✔ Use `th` for table headers

---

## tabindex

```
tabindex="0"
```

Keyboard focus.

Use:

- `0`
- `-1`

Never use values greater than **0**.

---

## accesskey

Creates keyboard shortcuts.

```html
accesskey="h"
```

---

# 18. WAI-ARIA

ARIA improves accessibility when HTML alone isn't enough.

Common roles

```html
role="tab"

role="menu"

role="alert"
```

Useful attributes

```
aria-label
aria-labelledby
aria-describedby
aria-hidden
```

- `aria-label` → give an accessible name.
- `aria-labelledby` → use existing text as label.
- `aria-describedby` → extra description.
- `aria-hidden="true"` → hide decorative content from screen readers.
