What are ARIA roles |
---------------------

ARIA ROLES
----------------------------------------------------------------------------------------------
ARIA roles specify the semantic meaning of an HTML elements.
essential for people who use assistive technologies [Screen reader ect...].

Many semantic HTML elements already have an ARIA role assigned by default.
For example the <button> element has a default ARIA role of "button" :
----------------------------------------------------------------------------------------------
<button>Example button</button>
----------------------------------------------------------------------------------------------

But non-semantic element don't have a role, for example, screen readers will not know how to
interpret the purpose of a div if we don't specify it's role explicitly :
----------------------------------------------------------------------------------------------
<div>
    <!-- random element there -->
</div>
----------------------------------------------------------------------------------------------

To specify the ARIA role of an element, we just need to add the role="" attribute
where the value is the name of the role in the ARIA specification.
An example of role attribute with a value of "alert" would look like this:
----------------------------------------------------------------------------------------------
<link rel="stylesheet" href="styles.css">

<div class="alert" id="exp-warning" role="alert">
  <span class="hidden">Your log in session will expire in 3 minutes.</span>
</div>
----------------------------------------------------------------------------------------------




The main categories of ARIA roles:
----------------------------------------------------------------------------------------------
- Document structure roles
- Widget roles
- Landmark roles
- Live region roles
- Window roles
- Abstract roles
----------------------------------------------------------------------------------------------


Document structure roles.
----------------------------------------------------------------------------------------------
Document structure roles define the overall structure of the web page.
With these roles assistive technologies can understand the relationships between different
sections and help users navigate the content.

However, most of the document structure roles are not used in modern web development
[Are we deadass] because browser already support equivalent semantic HTML elements.



We should focus on role that don't have semantic equivalent, for example :
----------------------------------------------------------------------------------------------
- toolbar
- tooltip
- feed
- math
- presentation
- none
- note
----------------------------------------------------------------------------------------------


For example here's what's a <div> with the "math" ARIA role would look like :
----------------------------------------------------------------------------------------------
<link rel="stylesheet" href="styles.css">

<div role="math" aria-label="x squared + y squared = 3">
  x<sup>2</sup> + y<sup>2</sup> = 3
</div>
----------------------------------------------------------------------------------------------
The value of the "arial-label" attribute should be a string that represent the expression.



Example of widget roles :
----------------------------------------------------------------------------------------------
[when focusable]
- scrollbar
- searchbox
- separator
or also
- slider
- spinbutton
- switch
- tab
- tabpanel
- treeitem

An example of searchbox would look like this :
----------------------------------------------------------------------------------------------
<div class="search-container" role="search">
  <label for="searchbox" class="visually-hidden">Search</label>

  <div
    id="searchbox"
    class="searchbox"
    role="searchbox"
    aria-label="Search the site"
    tabindex="0"
    contenteditable="true">
  </div>

  <button type="button" aria-label="Submit search">Search</button>
</div>
----------------------------------------------------------------------------------------------




Aria-hidden attribute :
----------------------------------------------------------------------------------------------
If we ever need to hide something to assistive technology we can use the "aria-hidden" attribute.
however it does not remove the DOM of the original element.
----------------------------------------------------------------------------------------------


"Aria-describedby" attribute :
----------------------------------------------------------------------------------------------
Used to provide addtional information about an element to screen reader users by
referencing existing content on the page. It create a programmatic association between the
element and the content.
----------------------------------------------------------------------------------------------
